# Chinese Xiangqi 2.00

## 项目简介

一个完整的中国象棋游戏系统，包含客户端和服务器端，支持在线对战。

## 项目特色

- 完整的象棋规则实现
- 网络对战功能
- 服务器控制台管理
- 流畅的用户界面
